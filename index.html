¿Cómo generar el archivo repos.json con GitHub CLI?

GitHub CLI (gh)

Abre tu terminal en la carpeta correspondiente y utiliza la herramienta gh para exportar tus repositorios directamente a JSON:

gh repo list ORGANIZACIÓN --limit n --json name,url > repos.json
Ejemplo práctico en Windows Terminal / CMD:
C:\Users\usuario\Documents\GitHub> gh repo list ORGANIZACIÓN --limit n --json name,url > repos.json
ORGANIZACIÓN debe contener el nombre exacto de la organización (o usuario) cuyos repositorios se van a listar. Es sensible a mayúsculas y minúsculas (case-sensitive).
Donde n representa un número mayor o igual que el total de repositorios que deseas listar (ej. 50, 100, 500).
